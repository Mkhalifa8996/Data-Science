# 🔬 Advanced Data Science & Deep Learning Repository

Welcome to my primary Data Science repository. This repository architecture serves as a production-grade portfolio showcasing advanced research directions in **Deep Learning**, **Knowledge Distillation (KD)**, and **Metric-Optimized Image Processing**. 

The frameworks enclosed are designed to handle complex multivariate datasets, utilizing compressed neural networks optimized for efficient edge deployment and low-latency real-time inference.

---

## 📂 Repository Structure

The repository is modularly structured into dedicated research pipelines:

### 1. [🧪 MK-Model](./MK-Model/)
* **Project Title:** Metric-Optimized Knowledge Distillation for Ultrasound De-speckling
* **Core Contribution:** Formulated a breakthrough metric-guided loss function integrating **PSNR, SSIM, and MSE** directly into the objective function.
* **Academic Impact:** Published in ***Nature - Scientific Reports***.
* **Tech Stack:** TensorFlow, Keras, OpenCV, SciPy, Scikit-Image.
* **Interactive Notebook:** [Explore on Kaggle](https://www.kaggle.com/code/mostafakhalifa/mk-model) | **Publication:** [Read on Nature](https://www.nature.com/articles/s41598-025-07115-1)

### 2. [👁️ DIAA-Model](./DIAA-Model/)
* **Project Title:** Distillation with Illumination-aware Adaptive Attention
* **Core Contribution:** Implemented adaptive attention mechanisms to dynamically assess pixel-level image quality under variable lighting conditions.
* **Application:** Lightweight, real-time computer vision enhancement models.
* **Tech Stack:** Python, TensorFlow, Pandas, Matplotlib, PIL.
* **Interactive Notebook:** [Explore on Kaggle](https://www.kaggle.com/code/mostafakhalifa/diaa-model) | **Publication:** [Read on International
Journal of Computers and Informatics (Zagazig University)](https://www.ijci.zu.edu.eg/index.php/ijci/article/view/146)

- **Knowledge Distillation Workflow:** Competency in distilling complex, high-dimensional teacher networks (e.g., high-capacity UNets) into efficient student networks.
- **Multivariate Data Engineering:** Automated data cleansing and signal extraction pipelines, converting raw multivariate datasets into structured data-visualizations and analytical summaries.
- **Statistical Valuation Metrics:** Deep optimization through hybrid loss functions mapping structural coherence and edge preservation.
