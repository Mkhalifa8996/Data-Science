# DIAA: Distillation with Illumination-aware Adaptive Attention

This repository contains the implementation of the **DIAA Model**, a cutting-edge Deep Learning framework designed for low-light image enhancement.

## 🚀 Overview
The DIAA model leverages a **Knowledge Distillation-based architecture** combined with an **Illumination-aware Adaptive Attention** mechanism. It aims to effectively enhance low-light visibility, reduce unstructured noise, and preserve critical spatial and structural details for downstream computer vision tasks.

## 🛠️ Key Features
- **Adaptive Attention:** Dynamically adjusts to varying lighting conditions across the frame.
- **Knowledge Distillation:** Compresses complex teacher-network knowledge into an efficient student model suitable for real-time deployment.
- **Noise Reduction:** Advanced de-noising capabilities without sacrificing structural edges.
